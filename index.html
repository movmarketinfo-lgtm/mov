Concept

スマホをしまって、
外に出るだけでいい

Kiokuは「ながらスマホ」の逆を行くアプリ。
画面を見なくていい。操作しなくていい。
ただ外を歩くだけで、知らない誰かとすれ違い、記憶が積もっていく。

夜、家に帰ってポストを開けると、今日の出会いが届いている。
📵
画面を見なくていい
バックグラウンド動作。ながらスマホ・スマホ運転対策にもなる
🌀
偶然の出会いだけ
マッチングでもなく、フォローでもない。すれ違った事実だけが残る
🌙
夜に開く楽しみ
溜めるほどレアが出る。日記を開くような習慣が生まれる

Core Features

主要機能

📬
ポスト開封（30分に1回）
ホーム画面のポストを押すと溜まったすれ違いを開封。30分に1回のみ。件数はデザインで一目でわかる。多いほどレアリティUP。未開封の間は同じ相手との再すれ違いはカウントされない。
🃏
プロフィールカード
ニックネーム・一言・好きな音楽など事前設定した情報だけが届く。MBTI由来の色・デザインが個性を表す。
📷
写真共有（1枚・24時間）
すれ違い後24時間以内に1枚だけ送れる。キャプション不可。30日後に消えるが、キオク帳にシルエットが残る。
📖
キオク帳
すれ違い・写真・瓶が時系列で積もる「出会いの日記」。消えた写真のシルエットも残る。場所・天気・時刻が自動記録。
🧪
素材クラフト
集めた素材カードを組み合わせてアイテムを制作。作ったアイテムで自分のプロフィールカードを装飾できる。
✨
よく会う人
3回以上すれ違った相手はそっとマーク。そら瓶が解放される。会話はできないが、気づける。

Bottle Messages

2種類の瓶

Kiokuには2種類のメッセージボトルがある。空を渡るものと、海に沈むもの。

🫙
そら瓶
そらびん
3回すれ違った特定の相手への手紙。空を漂い、次のすれ違いで届く。返信もまた、次のすれ違いを待つ。
· 3回すれ違いで解放
· 次のすれ違いで必ず届く
· 登録から1週間は送信不可（受信はできる）
· 読まれたら消える
🍶
うみ瓶
うみびん
公式スポットの海底に沈んでいる手紙。そのスポットを訪れた証として置いていく。次の誰かが拾う。
· 公式スポット限定
· 誰でも読める・置ける
· 場所に紐づいた記憶として残る
· 拾われても消えない（複数人が読める）

User Flow

1日の使い方

朝
スマホをしまって外に出る 無料
アプリはバックグラウンドで動作。画面を見なくていい。ながらスマホにならない。
昼
公式スポットへ スポット
記憶箱を開ける（1日1回）。カードトレード。うみ瓶を置いたり拾ったりする。このときだけ画面を見る。
夕
ポストを開封 無料
30分に1回押せるポストボタン。溜まっているほどレアが出やすい。今日の出会いを確認。
夜
クラフト・装飾・瓶を書く 無料
集めた素材でアイテムをクラフト。自分のカードを装飾。3回会った相手へのそら瓶を書く。写真を1枚送る。

カードトレード可
サブスクユーザーが設定
1日1回・設置場所は自由
設置から1時間だけ有効
広さはプランで変わる
記憶箱・うみ瓶はなし
お気に入りスポットの仕様
1日1回、好きな場所を選んで設定できる「1時間限定のスポット」。設定してから1時間だけその場所がレアリティボーナス対象になり、時間が過ぎると自動的に無効化される。常設の「庭」ではなく、その日その時の「狙い目」を作る感覚。場所は毎回自由に選べるため、待ち伏せ的な固定化リスクも低い。
無料ユーザーのカードトレード
無料ユーザーは自分でスポットを作れないが、公式スポットまたは他のサブスクユーザーが設定中の1時間限定スポット内であればトレード参加可能。クラフトに必要な色を集めるために活用。

Safety Design

安全設計

最重要
通知は即時ではない
すれ違いは記録されるが通知はポスト開封まで届かない。座標も渡さない。場所の特定・追跡が構造的に不可能。
最重要
電話番号ブロック（事前登録）
相手がアプリを使っているか確認できない状態で、電話番号を登録しておくだけでその相手とのすれ違い検出自体をゼロにする。通知なし・完全な非表示。電話番号はハッシュ化して保存。DV・ストーカー被害者向け安全網。
最重要
そら瓶は登録1週間後から送信可
新規アカウントからの嫌がらせ防止。受信は初日からできるので体験を損なわない。
最重要
ポスト未開封中は同じ相手とのすれ違い不可
ポストを開封するまで、同じ相手との2回目以降のすれ違いは記録されない。意図的に追いかけて回数を稼ぐ行為が無意味になる。「よく会う人」判定・そら瓶解放にも同様に適用。
重要
同一日のすれ違いは1カウント
1日に何度近づいてもそら瓶解放カウントは1回のみ。意図的に3回近づく動機を排除。
重要
写真・瓶に通報・拒否を常設
受け取り拒否・ブロック・通報ボタンをすべてのコンテンツUIに必ず表示。
補助
写真はE2E暗号化・30日で自動削除
サーバーには暗号化済みで保持。消えることを演出として昇華（シルエットが残る）。
